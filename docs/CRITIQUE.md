# How this stacks up against the big benchmarks

Aug 8, 2026. I sat down and compared this project honestly against the benchmarks people actually cite — τ-bench, AgentBench, WebArena, SWE-bench, ToolLLM, API-Bank, and the two reliability papers. Everything below I checked against the actual papers, not secondhand summaries.

## The short version

Nobody else tests small models for reliability. τ-bench explicitly excluded 7B/13B models as too difficult for the benchmark. Everything else reports single-run success on frontier models. That's the gap this fills. But the big benchmarks beat me on scale and realism, no question — details below.

## Where they beat me

**Scale.** They run 165–2,294 tasks; I have 31 for capability. Statistical power is limited — only 2 of 8 models differ from the leader after correction. What I did about it: Wilson CIs, Fisher exact tests, effect sizes, an honest limitations section. The category table shows per-category n (3–5 tasks) so readers can weigh the small-n claims themselves.

**Multi-trial evaluation.** τ-bench's whole point is pass^k — consistency under repeats. I only do k=3 on 3 tasks; the 31-task suite is single-run. Added limitation #10 admitting this, plus a discussion paragraph connecting my consistency results to their pass^8 < 25% finding (GPT-4o retail). My t=0 reruns are a conservative lower bound on production inconsistency.

**Realism.** WebArena and SWE-bench use real environments; mine is a synthetic sandbox with state-based verifiers. Disclosed (#4, #9). Not going to dress it up as something it's not.

**Human evaluation.** They have it; I don't. Single-author keyword-based safety scoring plus deterministic verifiers. Disclosed (#5, #9). If I had funding, this is the first thing I'd buy.

**Figures.** They run ~6–7 each; I now have 13 figures + 10 tables covering every claim. Calling this one even.

## Where this wins

- Only reliability study on a multi-model sub-10B cohort. τ-bench excluded small models; everyone else tests frontier.
- Heavier stats than any of them: Wilson CIs, BH-corrected Fisher tests, Cohen's h, bootstrap CIs, exact permutation tests. None of the reference leaderboards report inferential statistics.
- Fully open source — harness, tasks, verifiers, traces, configs.

## Numbers I verified (so I don't misquote them later)

- τ-bench: 115 retail + 50 airline = 165 tasks; k∈{1,2,5,8}; GPT-4o pass^1 ≈ 61% retail / ≈ 35% airline; pass^8 < 25% retail; agent temp 0.0, user temp 1.0. (arxiv.org/abs/2406.12045)
- WebArena: 812 tasks, best GPT-4 agent 10.59%. (webarena.dev/static/paper.pdf)
- SWE-bench: 2,294 full instances, 500 Verified. (swebench.com)
- AgentBench: 8 environments, 27 LLMs, 269 dev / 1,091 test queries. (arxiv.org/abs/2308.03688)
