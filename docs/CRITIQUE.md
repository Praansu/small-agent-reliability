# CRITIQUE — Small Agent Reliability Paper vs. Popular Benchmarks

Date: 2026-08-08. This document records the meticulous side-by-side comparison of
`small-agent-reliability` against popular agent-evaluation papers, the gaps found,
and the upgrades applied. All statements about external papers were verified
against the actual papers/websites at the time of writing.

## 2. What they do better (meticulous criticism)

### 2.1 Scale of task suites
- τ-bench / WebArena / SWE-bench evaluate 165 / 812 / 2,294 tasks. We evaluate
  31 for capability. Statistical power is limited: only 2 of 8 models differ from
  the leader after BH correction. **Mitigation already in paper:** Wilson CIs,
  Fisher exact tests, Cohen's h, effect sizes, honest limitations text.
- **Upgrade applied:** category-level table (tab:category_results) makes the
  per-category n explicit (3–5 tasks per category), so readers can weigh the
  granular claims themselves.

### 2.2 Multi-trial evaluation
- τ-bench's core contribution is pass^k: consistency under repeated i.i.d. trials.
  We run k=3 for consistency on 3 tasks only; the 31-task capability suite is
  single-run. **Upgrade applied:** added explicit limitation #10 admitting this,
  plus a Discussion paragraph connecting our consistency findings to τ-bench's
  pass^8 < 25% result (GPT-4o retail), and clarifying that our t=0 repeated runs
  are a conservative lower bound on production inconsistency.

### 2.3 Realism / sim-to-real
- WebArena and SWE-bench use real environments; our sandbox is synthetic with
  state-based verifiers. Already disclosed (limitation #4, #9). No upgrade needed —
  adding a fake realism claim would be worse than the honest limitation.

### 2.4 Human evaluation
- τ-bench validates a subset with human comparison; WebArena used human
  annotation of task feasibility; SWE-bench used human verification of patches.
  We have none — single-author keyword-based safety scoring and deterministic
  verifiers. Already disclosed (#5, #9). Flagged as the #1 cost item for a
  journal-length extension.

### 2.5 Number of figures/tables
- τ-bench: ~7 figures; SWE-bench: ~6; WebArena: ~7. We now have **13 figures +
  10 tables**, covering every claim. This is no longer a weakness.

### 2.6 What we do better (honest upside)
- **Only study evaluating reliability dimensions on a multi-model sub-10B cohort.**
  τ-bench explicitly excludes small models. AgentBench/WebArena/SWE-bench report
  single-run success only.
- **Statistical rigor exceeds all reference points**: Wilson CIs, BH-corrected
  Fisher tests, Cohen's h, bootstrap CIs, exact permutation tests — none of the
  reference benchmarks report inferential statistics on their leaderboards.
- Full open-source reproducibility (harness, tasks, verifiers, traces, configs).

## 4. Verified numbers used in the comparison
